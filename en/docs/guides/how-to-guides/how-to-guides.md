# How to Guides

Step-by-step walkthroughs that build a complete, working project in
WSO2 Agent Builder, from creating the agentic integration to running
and testing it. Each guide covers a different pattern:

- **Build a Sentiment Analyzer**: an AI agent exposed through a typed
  HTTP trigger that returns a validated, typed result.
- **Email Generator with Direct LLM**: a single direct LLM call behind
  an HTTP endpoint, with no agent at run time.
- **Build a Hotel Finder Agent**: an agent with custom tools, exposed
  through an Agent Chat trigger.

These are the How to Guides from the full catalog on the main
[Guides](/guides) page.
